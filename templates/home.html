CORE FEATURES

Everything needed for a secure paper workflow

Each stage is controlled so that question papers remain protected from upload to release.

01

Secure Login

Password authentication with OTP verification before system access.

02

Role-Based Access

Admin, Question Setter, Reviewer and Exam Centre receive separate permissions.

03

Encrypted Storage

PDF question papers are encrypted with AES-GCM before being stored.

04

Review & Approval

Reviewers can inspect papers and record approval or rejection.

05

Controlled Release

Only an approved paper can be released after its scheduled time.

06

Audit Monitoring

Login, upload, review, release and access events are recorded in audit logs.
